### Инструкция для ИИ-агента: Логика выгрузки данных из одного топика

**Цель:** Реализовать скачивание всех текстовых сообщений и фотографий из конкретного (одного) Telegram-топика и сохранить их в локальную папку для проверки работоспособности парсера.

**Требования к процессу (Пошаговый алгоритм):**

#### Шаг 1: Подготовка файловой системы

* Скрипт должен получить `topic_id` целевого топика.
* В корне проекта (или в директории `downloads/`) необходимо автоматически создать отдельную папку для этого топика.
* Имя папки должно быть понятным, например: `downloads/topic_[ID_топика]`. Если папка уже существует, скрипт должен продолжать работу с ней.

#### Шаг 2: Получение истории сообщений

* Использовать метод итерации по истории сообщений чата (`iter_messages`).
* **Критически важно:** Фильтровать сообщения так, чтобы получать только те, которые принадлежат нашему топику. Для этого в Telethon используется параметр ответа на ID топика (`reply_to=topic_id`).
* Рекомендуется установить лимит количества сообщений для первого теста (например, последние 50-100 сообщений в топике), чтобы не ждать слишком долго.

#### Шаг 3: Обработка и сохранение текста

* Скрипт должен проверять каждое сообщение на наличие текста.
* Если текст есть, его нужно сохранить в единый текстовый файл внутри папки топика (например, в файл `messages_log.txt`).
* Формат записи в текстовый файл должен быть читаемым: `[Дата и время] | [ID сообщения] | Текст сообщения` и разделитель между сообщениями. Это поможет нам глазами найти списки оборудования.

#### Шаг 4: Обработка и скачивание фотографий (Медиа)

* Скрипт должен проверять, содержит ли сообщение вложения (медиа).
* Если вложение является фотографией (`MessageMediaPhoto`), скрипт должен скачать этот файл в созданную папку топика.
* Имя сохраненного файла должно быть уникальным и информативным, например: `photo_[message_id].jpg`.
* *Важное замечание для агента:* В Telegram фотографии часто отправляются "альбомами" (медиа-группами). Скрипт должен корректно обрабатывать такие группы, скачивая каждую фотографию из альбома.

#### Шаг 5: Безопасность и лимиты (Rate Limiting)

* При скачивании файлов обязательно добавить небольшую асинхронную паузу (например, 0.5 - 1 секунда) между загрузками.
* Скрипт должен корректно перехватывать ошибку `FloodWaitError` от Telegram, автоматически ждать указанное сервером время и продолжать загрузку.

#### Шаг 6: Индикация работы

* Во время выполнения скрипт должен выводить в консоль (через `logger`) понятные сообщения:
* *"Создана папка для топика..."*
* *"Найдено сообщение с текстом (ID: ...), сохранено."*
* *"Скачивается фотография (ID: ...)..."*
* *"Загрузка топика завершена. Всего скачано X фото и Y текстовых сообщений."*
