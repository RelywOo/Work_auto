# Telegram Authentication & Topic Viewer

Простой проект для входа в Telegram и просмотра последних топиков из супергруппы с использованием Telethon.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте переменные окружения:
   - Скопируйте `.env.example` в `.env`
   - Заполните ваши данные в `.env` файле:
     - `TELEGRAM_API_ID` - ваш API ID от Telegram
     - `TELEGRAM_API_HASH` - ваш API Hash от Telegram
     - `TELEGRAM_PHONE_NUMBER` - ваш номер телефона
     - `TELEGRAM_2FA_PASSWORD` - пароль 2FA (если включен)
     - `TARGET_CHAT_ID` - ID супергруппы для просмотра топиков

## Запуск

```bash
python main.py
```

При первом запуске потребуется ввести код подтверждения из Telegram.

## Функционал

- 🔐 **Аутентификация в Telegram** - автоматический вход с сохранением сессии
- 📋 **Просмотр топиков** - отображение 7 последних топиков из указанной супергруппы
- 📊 **Информация о топиках** - ID, название и дата создания каждого топика
